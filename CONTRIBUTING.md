# Contributing

OpenCanvas is actively developed under Mathew Minguel's direction. Start with a focused issue describing the problem, expected behavior, browser, and steps to reproduce it. Keep sample designs fictional and avoid private client information.

Before a substantial code or design contribution, discuss scope and licensing with the maintainer. A project-wide reuse/contribution license is still pending. Do not submit copied proprietary code or assets without documented permission.

For a proposed change:

1. Read the [development notes](docs/DEVELOPMENT.md) and existing feature code.
2. Keep the change focused and preserve existing editable project formats.
3. Rebuild the affected feature modules in the documented order.
4. Run `npm test` and `npm run check`.
5. Test affected interactions in a browser. Include useful screenshots and state any remaining limits.
6. Keep source/author/license records with newly introduced dependencies, fonts, or artwork.

Do not include credentials, real personal designs, local storage dumps, deployment identities, or private hosting configuration in a pull request. AI-assisted contributions should describe the assistance and the human review performed.
