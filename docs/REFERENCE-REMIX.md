# Reference Remix — 240 combinations

This collection combines broad design directions from the three supplied gallery screenshots. It adds **240 editable combinations: 20 layout families × 12 variations**, rather than claiming 240 independently art-directed layouts. Each has its own title, palette and editable project identity. Families interleave in gallery order so consecutive cards use different compositions. Photo subjects cycle within suitable topics, with varied framing and lettering.

Families: chrome exhibition, portrait editorial, vinyl night, skeleton invitation, horror headline, striped brand card, birthday portrait, creator notebook, studio wordmark, career résumé, board-game path, event schedule, picnic invitation, seasonal market, monthly planner, sign-up sheet, travel cover, restaurant seal, analog broadcast, and photo scrapbook.

The monthly planners cover all twelve months of 2027 with calculated weekday alignment and correct month lengths. Sign-up sheets contain eight blank rows. These are editable graphic templates, not interactive data-collection forms. Travel and broadcast covers are static artwork, not videos.

Two new assets were made with OpenAI's built-in image generation tool: assets/people/mix-beach.jpg and assets/people/mix-picnic.jpg. Full prompts and provenance are in [the asset manifest](../assets/people/PROVENANCE.json). Existing documented project assets are reused; fictional generated people and places do not represent real endorsements or verified travel locations. No Canva template files, source code or stock artwork were copied.

Validation: 76 automated checks in the repository, including every new composition's bounds, image proportions, editable titles, search metadata and independent IDs; calendar dates; and contrast on previously problematic paper and invitation panels. Browser checks cover all 240 cards loading through pagination, topic searches, and export.

Library total: 1,213 template entries, displayed as 445 cards by default after grouping older style/size variations. The Reference Remix collection displays all 240 combinations.
