# Signature collection

Twenty original compositions built entirely from editable text and native shapes. This collection uses no generated images, stock photographs, remote image URLs, or flattened template previews. Typography uses the open font families already bundled with OpenCanvas; their licenses and source records remain in `vendor/fonts/`.

Each entry is one composition, not a set of color permutations. The collection includes a transit-map rave poster, optical acid-house bill, typesetter ticket, curved vinyl label, warehouse announcement, frequency study, sunset day-party cover, jazz score, market sticker sheet, serif beauty invitation, folded club bill, exhibition geometry, festival timetable, diagonal breakbeat poster, fashion launch billboard, podcast punctuation, celebration invitation, workshop index, vertical sound-wave story, and cafe card.

Sizes include portrait posts, square social designs, landscape covers and a tall story. Dates, artist names, venues, contact details and calls to action are editable samples. Replace these details before publishing. No named venue, performer or organization is being endorsed.

## Editing and portability

- Text, decorations and background colors can be edited separately.
- The vinyl-label title uses the actual curved-text tool.
- All layouts stay under 250 layers, leaving room for personal photos, logos and additional copy.
- Designs remain editable after export and reimport as OpenCanvas project files.
- The collection does not add an asset download, font request or runtime image-generation service.

The collection was reviewed as a contact sheet and at individual design size. Native-font measurements check the supplied text against its boxes; new wording may require resizing. Automated checks cover distinct compositions and formats, native-layer editability, project validation and round trips, layer bounds, source-free imagery metadata, and actionable sample details.

Source implementation: `signature-collection.js`. The public catalog groups these as **Signature · 20 designs**. This collection is original OpenCanvas work by Mathew Minguel with development and layout assistance from OpenAI Codex. It does not contain Canva template files or proprietary artwork.
