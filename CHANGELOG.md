# Changelog

## Unreleased — workspace and layout tools

Prepared October 14, 2026. OpenCanvas remains an independent work in progress.

- Added Signature: 20 original compositions with editable typography and native shapes, without new raster or AI imagery. Featured discovery mixes selected Signature and Art directed designs. The executable catalog now contains 1,397 entries and 629 default design cards.
- Added Home folders, per-project folder assignment, recoverable Trash, and restoration to the original folder. Workspace backups preserve folders and trashed projects.
- Restored the last active project after the local workspace and feature modules finish loading. Startup no longer saves an untouched starter as a phantom project; custom font and page metadata are ready before restoration.
- Added page rulers, up to 30 manual guides per page, numeric and keyboard positioning, and guide snapping. Guides remain outside exported artwork.
- Added editable two- or three-color linear/radial gradients on pages and supported shapes, including project persistence, undo, and Canvas/SVG rendering.
- Added current-page SVG downloads and multipage SVG ZIP export. Supported text and shapes remain vectors; image layers are embedded raster artwork. Available fonts can be embedded, and supported layer links and descriptions are retained.
- Checked SVG text curves and effects against native canvas rendering, font embedding, cancellation during image preparation, layout metadata, project recovery, and template geometry. See the [workspace and layout guide](docs/WORKSPACE-AND-LAYOUT.md) for practical limits.
